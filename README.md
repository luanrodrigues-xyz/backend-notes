# Backend Notes

Artigos e anotações sobre **Java, Spring Boot, persistência, concorrência, arquitetura e testes**.

Este repositório reúne estudos sobre o comportamento da linguagem, exemplos que podem ser executados e decisões comuns no desenvolvimento backend. Os textos são escritos em português e podem ser lidos diretamente no GitHub, sem site ou gerador estático.

## Código dos artigos

Os exemplos completos ficam em [examples/](examples/). Os códigos Java são independentes de frameworks; veja as instruções no diretório de cada exemplo.

## Organização

- `articles/java/`: fundamentos, coleções, concorrência e JVM
- `articles/spring/`: Spring Boot, Web, Security e transações
- `articles/persistencia/`: SQL, JPA e bancos de dados
- `articles/arquitetura/`: design e arquitetura de sistemas
- `articles/testes/`: testes unitários, integração e ferramentas
- `examples/`: código-fonte executável relacionado aos artigos

As categorias só ganham diretórios à medida que novos artigos forem publicados.
